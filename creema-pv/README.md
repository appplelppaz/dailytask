# Creema カテゴリー別 期間PV調査

Creema の「シューズ・靴」カテゴリー(人気上位25%)について、**指定した期間中に作品ページが何回見られたか(PV)** を調べます。無料です。

## しくみ

Creema の作品ページには「PV(閲覧回数)」の**累計**が表示されています。期間の始めと終わりに全対象作品の PV を記録し、その差を取ると期間中の PV になります。

- 対象: 「人気の作品」順(Creema の既定の並び)の上位25%。2026年9月25日時点で全11,565作品 → 2,892作品。広告(PR)枠は順位に含めない
- 同時に記録するもの: お気に入り数・販売数(ページ内データ)・価格・ショップ名・小カテゴリー(パンプス、スリッポンなど)
- **過去の期間は調べられません**。記録を始めた日以降の期間だけ分かります

## 使い方(Windows)

1. **期間の初日**に `記録する.bat` をダブルクリック → 約3時間で `snapshots` フォルダに記録ができます
   (初回は必要な部品を自動で入れるので数分余計にかかります。途中で閉じても、もう一度実行すれば続きから再開します)
2. **期間の最終日**にもう一度 `記録する.bat`
3. `比較する.bat` をダブルクリック → 最初と最新の記録を比べた Excel が `snapshots` フォルダにできます

Excel のシート:

| シート | 内容 |
|---|---|
| 概要 | 期間、比較できた作品数、期間PV合計、1日あたりPV、お気に入り増 |
| 作品別 | 作品ごとの期間PV・お気に入り増・販売数増(期間PVの多い順) |
| 小カテゴリー別 | パンプス/スニーカー/サンダル… ごとの期間PVとシェア |
| ショップ別 | ショップごとの期間PVとシェア |
| 価格帯別 | 価格帯ごとの期間PVとシェア |

特定の2つの記録を比べたいときは、コマンドで `python creema_pv.py compare 開始.csv 終了.csv` と指定します。

## 数字の読み方と注意

- **PV = Creema 内で作品ページが開かれた回数**。Google 検索から来た人も、Creema 内で探した人も区別されません。「流入元」は分かりません
- **このツールが作品ページを開くと、PV も1増えます**(実際に確認済み)。比較のときに、記録で開いた回数を自動で差し引いています
- 集計の対象は「開始時の人気上位25%」の作品です。カテゴリー全体の PV ではありません。期間中に新しく出てきた作品は入りません(2回目の記録では上位に入った新作も記録するので、次の期間の比較には入ります)
- 「人気の作品」の並びは時間で入れ替わります(数分で上位が入れ替わることを確認)。そのため2回目以降の記録では、1回目に記録した作品が上位から外れていても追いかけて記録します
- 「販売数」は作品ページ内のデータ(`count_sold_items`)の差です。Creema は意味を公開していないので参考値です
- 削除・非公開になった作品は「取得できず」と記録され、比較から外れます

## Creema への配慮

- 1件ずつ、2秒以上の間隔を空けて取得します(robots.txt の「Let's crawl gently」に沿う)。robots.txt で禁止されたページは使いません
- Creema の利用規約には「他の会員等の個人情報を収集・蓄積する行為」を禁じる条項があり、ここでの「個人情報」には会員が掲載したデータも含むと広く定義されています。スクレイピングを名指しで禁じる条文は見つかりませんでしたが、グレーな部分があります。**自社の参考に使うだけにとどめ、データを公開・再配布しないでください**
- 記録するたびに対象作品の PV が1ずつ増えます。記録は期間の始めと終わりの2回程度にしてください

## 別のカテゴリーを調べるとき

`記録する.bat` の `--category 83` を別の番号に変えます。番号は Creema のカテゴリーページの URL(`https://www.creema.jp/listing/83` の `83`)です。割合は `--top-percent 25` で変えられます。
