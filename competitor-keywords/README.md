# 競合商品 検索キーワード分析

競合の EC 商品ページの URL を入れると、その商品ページがどの検索キーワードで Google に表示されているかを調べます。順位・検索ボリューム・推定クリック・検索意図・カテゴリー(幅・足の悩み・年代・用途…)をまとめ、複数の商品を比べられます。

- 使い方: **起動 → URLを貼る → 「分析開始」 → 結果を見る → Excel/CSVで保存**
- すべての数字に「データ種別(実測/外部DB/候補)」「信頼度」「根拠」が付きます
- 推定クリックはモデル値です。**競合の実際のアクセス数ではありません**

なぜこの構成にしたのか(他の方法との比較・料金・正確性・制約)は [docs/調査と設計.md](docs/調査と設計.md) にまとめています。

---

## はじめて使うとき(Windows)

1. このフォルダ(`competitor-keywords`)を PC の好きな場所に置きます
   (GitHub からは「Code → Download ZIP」でダウンロードし、ZIP を展開)
2. `start.bat` をダブルクリック
   - 初回だけ必要な部品(Python など)を自動でダウンロードします。数分かかります
   - 「WindowsによってPCが保護されました」と出たら「詳細情報 → 実行」
3. ブラウザで画面が開きます。使い終わったら黒い画面を閉じてください

2回目からは `start.bat` をダブルクリックするだけです。デスクトップにショートカットを作ると便利です(右クリック → 送る → デスクトップ)。

Mac の場合は `start.sh` を使います。

## 使い方

1. 「① 分析する」タブの欄に、競合商品の URL を1行に1つずつ貼ります(10〜100件OK)
   - `A社 幅広パンプス, https://...` のように書くと、結果にその名前で表示されます
2. 「🔍 分析開始」を押します
3. 結果は次のタブで見られます
   - **② 商品別**: 商品ごとの主要キーワード(順位・検索ボリューム・推定クリック・検索意図・信頼度)
   - **③ 競合比較**: 商品×需要カテゴリーの比較、共通キーワード/独自キーワード
   - **④ 市場の検索需要**: 「幅広」「外反母趾」「40代」など特徴語ごとの検索需要の大きさ。AI による商品企画メモ(任意)
   - **⑤ データの見方**: 各列の意味と信頼度の説明
4. 「📥 Excelで保存」で、全シート(読み方・商品サマリー・キーワード詳細・比較・需要マップ・カテゴリー構成)を保存できます

過去の分析結果は左側の「過去の分析」からいつでも開けます(追加料金はかかりません)。

## 3つの使い方(料金別)

| | 無料 | 低コスト(おすすめ) | 高精度 |
|---|---|---|---|
| 必要な設定 | なし(Serper の無料キーがあると順位を実測) | + DataForSEO | + Ahrefs/Semrush の CSV、Claude |
| 月額の目安 | 0円 | 約 $5〜20(100商品を月1〜4回) | 月額契約 $130〜 + 左記 |
| 分かること | 商品ページが打ち出している特徴語と、その語で実際に何位か | 実際に表示されているキーワードの一覧・検索ボリューム・推定クリック | 2つのデータベースを比較・補完 |

設定は画面左の「⚙️ 設定(APIキー)」に貼って「保存」するだけです。キーはこの PC の `data/settings.json` にだけ保存されます。

### DataForSEO(低コスト版の中心。1商品約 $0.05)
1. https://dataforseo.com で無料登録(登録時に $1 分の無料枠)
2. ダッシュボードの「API Access」に表示されるログイン(メールアドレス)と API パスワードを設定画面に貼る
3. 本格的に使うときは $50 からチャージ(使った分だけ減ります)

### Serper(順位の実測。登録で 2,500 回無料)
1. https://serper.dev で無料登録
2. 表示された API キーを設定画面に貼る

### Claude(任意。辞書で分類できない語の分類と商品企画メモ)
1. https://console.anthropic.com で API キーを作成し、設定画面に貼る
2. 費用を抑えたい場合は「AIモデル」を `claude-haiku-4-5` などに変更できます

### Ahrefs / Semrush の CSV を使う
Ahrefs の「Organic keywords」や Semrush の「Organic Positions」で書き出した CSV を、「① 分析する」の「CSVを取り込む」から読み込めます。その商品には外部 API を使わないので追加料金はかかりません。

## よくある質問

**Q. 「推定クリック」は競合の売上や訪問数ですか?**
いいえ。「検索ボリューム × その順位で一般的にクリックされる割合」の計算値です。実際の数とは大きくずれることがあります。順位や需要の大きさの比較に使ってください。

**Q. 商品ページが「取得できませんでした」と出ます**
楽天・Amazon などはボット対策で取得を断ることがあります。DataForSEO や CSV を使った分析はそのままできます(「ページ内容との関連性」が「不明」になるだけです)。

**Q. DataForSEO に「データがありませんでした」と出ます**
小さなショップや新しいページはデータベースに無いことがあります。その商品は自動で無料モード(ページ内容から候補を作って実測)に切り替わります。

**Q. 分類の辞書を増やしたい**
`analyzer/taxonomy.py` の `CATEGORIES` に語を追加すると反映されます。ブランド名(指名検索の判定用)は同じファイルの `KNOWN_BRANDS` です。

## 開発者向け

```
competitor-keywords/
├── start.bat / start.sh     起動(uv が Python と依存パッケージを自動で用意)
├── app.py                   画面(Streamlit)
├── analyzer/
│   ├── pipeline.py          商品ごとの取得方法の選択と、行データの組み立て
│   ├── dataforseo.py        DataForSEO Labs(ranked_keywords / keyword_overview)
│   ├── serper.py            Serper(検索結果の実測)
│   ├── suggest.py           Google サジェスト
│   ├── page.py              商品ページ取得(robots.txt 準拠)と関連性判定
│   ├── csv_import.py        Ahrefs / Semrush CSV 取込
│   ├── taxonomy.py          女性靴の分類辞書・検索意図ルール
│   ├── metrics.py           推定クリック(CTRモデル)・信頼度
│   ├── compare.py           比較表・需要マップ
│   ├── ai.py                Claude による補助分類・企画メモ(任意)
│   ├── export.py            Excel / CSV
│   ├── cache.py             API結果のキャッシュ(SQLite、再課金防止)
│   └── config.py            設定・分析履歴の保存
├── tests/                   自動テスト(外部APIは模擬応答)
└── docs/調査と設計.md
```

- 環境変数でもキーを渡せます: `DATAFORSEO_LOGIN` `DATAFORSEO_PASSWORD` `SERPER_API_KEY` `ANTHROPIC_API_KEY` `AI_MODEL`
- テスト: `uv run pytest`
- `data/` フォルダ(設定・キャッシュ・分析履歴)は Git に含めません
