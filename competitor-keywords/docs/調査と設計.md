# 競合商品の検索キーワード分析 — 調査・比較・設計

調査日: 2026年9月25日。料金は各社サイト・公開情報の値で、為替・改定で変わります。

## 目的の整理

やりたいことは次の3段階です。

1. **商品単位の把握**: 競合の商品ページ1つが、どの検索キーワードで Google に表示されているか。順位・検索ボリューム・推定クリックも見たい
2. **複数商品の比較**: 10〜100商品で、共通して獲得しているキーワードと、1商品だけが獲得しているキーワードを見つける
3. **商品企画への利用**: キーワードを「幅・足の悩み・年代・用途…」に分けて、市場でどんな悩みや特徴が検索されているかを見る

難しいのは 1 です。競合の Search Console は見られないので、「どのキーワードで表示されているか」は外部から推定するしかありません。方法は次の3つです。

| 方法 | 仕組み | 長所 | 短所 |
|---|---|---|---|
| A. SEOデータ会社のDBを引く | Ahrefs・Semrush・DataForSEO などが、数億のキーワードで Google 検索結果を定期的に記録している。そのDBから「このURLが出ているキーワード」を取り出す | 自分では思いつかないキーワードも見つかる。検索ボリュームつき | 有料。観測は数週間おきなので今の順位とずれることがある。小さなサイトや、ロングテールしか持たないページはDBに無いことがある |
| B. 候補を作って実際に検索する | 商品ページの記載や Google サジェストからキーワード候補を作り、実際の検索結果にそのURLが出るかを確認する | 確認した日時点では確実(実測)。安い | 候補に無いキーワードは見つからない。検索ボリュームは分からない |
| C. AIに推測させる | ページ内容からAIが「検索されそうな語」を挙げる | 無料に近い | 根拠が無い。流入キーワードとして扱うのは不適切 |

Ahrefs で見た分析は A です。**A が本質的に必要**で、B はその裏付けと無料の代替、C は分類や要約の補助にとどめるのが妥当と判断しました。

## 1. おすすめの構成

**DataForSEO(従量課金)+ Serper(無料枠)+ 自作のローカル分析アプリ。Claude は任意**

- **DataForSEO Labs `ranked_keywords`**: Ahrefs の「Organic keywords」と同じ種類のデータ(URL→順位付きキーワード・検索ボリューム・検索意図)を API で取れる。日本(`location_code 2392` / `ja`)に対応。
  - 料金: 1リクエスト約 $0.012 + 1行約 $0.00012。**1商品300キーワードで約 $0.05、100商品で約 $5**。月額費用なし。最初のチャージは $50〜(新規登録時に $1 の無料枠あり)
- **Serper**: Google 検索結果を返す API。DataForSEO の上位キーワードを「今の検索結果」で確認し、「実測」に格上げするのに使う。**登録で 2,500 回分無料**、以降は 1,000 回あたり約 $1
- **自作アプリ(このリポジトリ)**: 分類辞書・比較表・需要マップ・Excel 出力。Windows ではダブルクリックで起動

なぜこれが最適か:

- 必要なデータ(A)を**使った分だけ**の料金で取れる。月に数回・100商品程度なら **月 $5〜20**。Ahrefs や Semrush の月額 $130〜500 に比べて 1/10 以下
- Ahrefs・Semrush の画面では「複数商品の共通/独自キーワード」「女性靴の悩み・年代・幅といった分類」「商品企画向けの集計」は自分で Excel 加工が必要。今回ほしいのはむしろこちらなので、**データは API で買い、分析は自作**が合う
- 同じ URL は保存した結果を再利用するので、同じ分析を何度開いても再課金されない

## 2. 無料で実現する方法(このアプリの「無料モード」)

キー無し、または Serper の無料キーだけで動きます。

1. 商品ページを取得し、タイトル・見出し・説明文・パンくず・本文から特徴語(幅広・4E・外反母趾・通勤…)を拾う
2. 「特徴語 + アイテム」と、Google サジェストのうちページの記載と合うものを候補にする(1商品25件ほど)
3. Serper キーがあれば、候補ごとに実際の検索結果(20位まで)を確認し、その商品ページが出ていれば「実測」の順位として記録する

**できること**: 各競合が商品ページで打ち出している特徴(=狙っている需要)の比較。候補が検索結果で本当に上位かの確認(実測)。サジェストに出るか(=検索されている証拠)。

**できないこと・精度の限界**:

- **検索ボリュームが分からない**(Google キーワードプランナーは広告を出していないと幅でしか出ない。自動取得も難しい)。推定クリックも出せない
- ページに書いていない語で流入しているキーワードは見つからない。Ahrefs と比べて**見つかるキーワード数は数分の一〜数十分の一**になる
- Serper の無料 2,500 回は、25候補×20位(2回分)で**約50商品分**。使い切ったら有料(それでも安い)

→ 「競合がどんな特徴を打ち出しているか」の比較には十分ですが、「実際にどんな検索需要を獲得しているか」は大きく欠けます。**分析の中心となる数字(キーワード網羅・ボリューム)は無料では取れない**、というのが結論です。

## 3. 低コストで精度を上げる方法 — どこにお金をかけると何が良くなるか

| | 無料版 | 低コスト版(おすすめ) | 高精度版 |
|---|---|---|---|
| 構成 | 無料モード + Serper 無料枠 | + DataForSEO(従量) | + Ahrefs か Semrush を必要な月だけ契約し CSV 取込、Claude で分類補助 |
| 月額の目安 | $0 | **$5〜20**(100商品を月1〜4回) | $130〜250 + 左記 |
| キーワードの見つけ方 | ページ記載 + サジェスト | 外部DBの全キーワード(最大1,000/商品) | 2社のDBを比較・補完 |
| 順位 | 実測(候補のみ) | DB観測値 + 上位を実測で確認 | 同左 |
| 検索ボリューム | なし | あり(推定) | あり(2社の値を比較できる) |
| 推定クリック | なし | あり(モデル値) | あり |
| 小規模サイトの商品 | ページが取れれば候補を実測 | DBに無い場合は自動で無料モードに切替 + 見つけた語のボリュームを取得 | Ahrefs の方がDBが大きく見つかる可能性が上がる |

効果の大きい順:

1. **DataForSEO(月 $5〜20)** — 効果が最も大きい。「実際に獲得しているキーワード」と検索ボリュームが入り、ツールの目的そのものが実現する
2. **Serper の有料クレジット($50で5万回)** — DB の順位を「今の実測」で確認できる件数が増える。信頼度「中」→「高」の行が増える
3. **Ahrefs/Semrush の短期契約** — DataForSEO の DB に無いページが多い場合だけ検討。1か月だけ契約して CSV を書き出し、このアプリに取り込めば解約後も分析は続けられる
4. **Claude API(任意、1回数十〜百円程度)** — 辞書で分類できない語の分類と、商品企画メモ。精度より手間の削減が目的

## 4. 完全自作する場合の仕組み

このリポジトリがそれにあたります(データは外部 API、分析は自作)。**キーワードの順位データベース自体を自作するのは現実的ではありません**。Ahrefs 並みにするには数億キーワードを定期的に検索し続ける必要があり、Google の検索結果を自動取得することは利用規約で禁止されています。

```
[画面 Streamlit(ブラウザで開くローカルアプリ)]
   │ URL一覧 / CSV
   ▼
[pipeline] 商品ごとに取得方法を自動選択
   ├─ CSV取込(Ahrefs/Semrush)       → 取込
   ├─ DataForSEO ranked_keywords      → 外部DB(推定)
   │     └─ 上位N件を Serper で確認   → 実測
   └─ 無料モード: ページ解析 + サジェスト → 候補 → Serper → 実測
   ▼
[分類] 女性靴の辞書(アイテム + 12カテゴリー・約300語) → 足りない分だけ Claude
[指標] 推定クリック = ボリューム × 順位別CTR(モデル値)、信頼度、ページ内容との関連性
   ▼
[比較] 商品×カテゴリー、キーワード×商品(共通/独自)、特徴語別の需要マップ
   ▼
[出力] 画面 / Excel(7シート) / CSV、結果はPC内に保存して再表示
```

ファイル構成は README を参照してください。

## 6. データの正確性

| データ | 種類 | どこまで信頼できるか |
|---|---|---|
| ページのタイトル・説明・価格・「ページ内容との関連性」 | **確認できる事実** | 取得日時点のページ内容そのもの |
| Serper で確認した順位 | **実測** | その日時点・日本・日本語・ログインなしの検索結果。個人の検索結果・地域・スマホ/PCで変わる |
| Google サジェストにあるか | **確認できる事実** | 検索されている証拠にはなるが、回数は分からない |
| DataForSEO / Ahrefs の順位 | **外部DBの観測値** | 観測日(表示あり)時点の値。数週間〜数か月前のことがある |
| 月間検索ボリューム | **外部の推定値** | Google 広告データ等をもとにした月平均。ロングテールは空欄やずれが大きい |
| 推定クリック | **モデル値** | ボリューム×一般的なCTR。広告やショッピング枠が多い商品系キーワードでは実際より高めに出やすい。**競合の実際のアクセス数ではない** |
| 検索意図 | **推定** | DataForSEO の機械学習、または辞書ルール |
| カテゴリー | **ルール判定**(一部 AI 推定) | 語が含まれるかの機械的判定。「AI推定」は要確認 |
| AI の商品企画メモ | **推測** | 仮説として表示。確認すべき事項も併記 |

画面・Excel のすべての行に「データ種別」「信頼度」「信頼度の理由」「観測日時」を付けています。

## 7. 制約(できないこと)

- **競合の実際の流入数は取得不可**: Search Console / Analytics は本人しか見られない。「推定流入」を実数のように見せる表示はしていない
- **Google の検索結果を自分で取得しない**: Google の利用規約は自動化されたアクセスによる検索結果の取得を禁じている。このツールは検索結果を提供する外部 API(Serper・DataForSEO)を使い、Google には直接アクセスしない。Google サジェストは非公式の仕組みで、将来使えなくなる可能性があるため少量・低頻度・キャッシュ付きで利用
- **Google 公式の検索 API は使えない**: Custom Search JSON API は新規受付終了、2027年1月1日で終了予定
- **競合サイトへのアクセス**: 取得するのは入力した商品ページ1枚だけ。robots.txt で禁止されていれば取得しない。同じサイトには2秒以上の間隔を空ける。楽天・Amazon・ZOZOTOWN などはボット対策で取得できないことがある(このクラウド環境からの試験では楽天は拒否された)。その場合もページ内容との関連性が「不明」になるだけで、DataForSEO や CSV による分析はできる
- **DataForSEO の DB に無いページ**: 小さなショップの商品ページは DB に無いことがある。その場合は自動で無料モード(候補を実測)に切り替える
- **API の制限**: DataForSEO は1回最大1,000キーワード/商品。Serper は10件ごとに1クレジット。Claude API は利用上限に達すると一時的に使えない
